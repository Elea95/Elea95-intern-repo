# Debugging React Native Apps (Flipper, Metro, and Console Logs) #21

How does Metro help in debugging a React Native app?

- Metro logs errors, warnings, and live updates in the terminal, helping developers debug issues in real time.

What debugging features does Flipper provide?

- Flipper offers logs, network inspection, React DevTools, crash reports, and UI debugging.

How can you inspect network requests in React Native?

- Use Flipper’s Network Plugin or log API responses manually using console.log().
